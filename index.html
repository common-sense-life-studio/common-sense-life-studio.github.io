Common Sense Life Studio

YouTube Shorts production tool / YouTube ショート制作ツール

About this application

Common Sense Life Studio is a private production tool operated by the owner of the YouTube channel “Common Sense Life Studio”. It renders short videos — entertainment fortune videos (Japanese zodiac / 四柱推命-based daily messages) and short space-science explainers — on the owner's own computer and uploads them to the owner's own YouTube channel using the YouTube Data API v3.

The application requests a single scope, https://www.googleapis.com/auth/youtube.force-ssl. It is used solely on the owner's channel to upload the owner's videos; set and update their title, description, tags and scheduled publish time; add them to the channel's own playlists (e.g. “Daily Fortune For Fun”, “Space”); and upload caption files (SRT, in English / Japanese / Korean) for those videos. It is not offered to the public, and no other users' data is accessed.

このアプリについて

Common Sense Life Studio は、YouTube チャンネル「Common Sense Life Studio」の運営者が使う非公開の制作ツールです。干支・四柱推命をもとにした娯楽向けの短い占い動画と、宇宙・科学を解説する短い動画を運営者のパソコン上で作成し、YouTube Data API v3 を使って運営者自身のチャンネルにアップロードします。

要求する権限は youtube.force-ssl の一つだけで、運営者自身のチャンネルでの動画のアップロード、タイトル・説明・タグ・公開予約の設定と変更、チャンネル内の再生リスト（Daily Fortune For Fun、Space など）への追加、その動画への字幕ファイル（SRT、英語・日本語・韓国語）のアップロードにだけ使用します。一般向けには提供しておらず、他のユーザーのデータにはアクセスしません。
