Privacy Policy
プライバシーポリシー

Last updated / 最終更新日: 2026-10-11

1. Data we access

Common Sense Life Studio (“the App”) accesses Google user data only through the YouTube Data API v3 with the youtube.upload scope, and only for the YouTube channel owned by the App's operator. The App uses this access to upload videos and to set their title, description, tags, privacy status and scheduled publish time. The App does not read, collect or store any other Google account data, viewer data or analytics.

2. How data is stored

The OAuth access/refresh token is stored only as a local file on the operator's own computer. It is not sent to any server operated by the App. Upload results (video ID, URL, upload time) are recorded in a local log file on the same computer.

3. Sharing

The App does not sell, share or transfer Google user data to any third party. Data is transmitted only to Google/YouTube as required to perform the upload.

4. Limited Use

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. YouTube API Services

The App uses YouTube API Services. By using the App, you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

6. Revoking access and deletion

Access can be revoked at any time from Google Account › Third-party apps & services. Deleting the local token file removes all stored credentials. To request deletion of any locally stored data, contact us below.
