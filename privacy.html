1. Data we access

Common Sense Life Studio (“the App”) accesses Google user data only through the YouTube Data API v3 with the single scope youtube.force-ssl, and only for the YouTube channel owned by the App's operator. The App uses this access to:

  • upload the operator's videos and set or update their title, description, tags, privacy status and scheduled publish time;
  • find or create the channel's own playlists (e.g. “Daily Fortune For Fun”, “Space”) and add uploaded videos to them;
  • upload caption files (SRT, in English / Japanese / Korean) for the operator's own uploaded videos.

Playlist titles of the operator's channel are read only to locate the target playlist, and the list of existing caption tracks (language and type) of the operator's own videos is read only to avoid uploading the same caption twice; neither is stored. The App does not read, collect or store any other Google account data, viewer data, comments or analytics.

2. How data is stored

The OAuth access/refresh token is stored only as a local file on the operator's own computer. It is not sent to any server operated by the App. Upload results (video ID, URL, upload time, scheduled publish time, playlist and uploaded caption languages) are recorded in a local log file on the same computer.

3. Sharing

The App does not sell, share or transfer Google user data to any third party. Data is transmitted only to Google/YouTube as required to perform the upload.

4. Limited Use

The App's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. YouTube API Services

The App uses YouTube API Services. By using the App, you are also bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

6. Revoking access and deletion

Access can be revoked at any time from Google Account › Third-party apps & services. Deleting the local token file removes all stored credentials. To request deletion of any locally stored data, contact us below.
